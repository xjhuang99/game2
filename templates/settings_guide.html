Whole-session controls

🧾 Total Rounds

Sets how many rounds appear in the schedule and how many standard rounds the match will play.

Example: enter 5 to create rows 1–5.

🛠️ Reset

Rebuilds the round table from the current Total Rounds value.

Important: rebuilding the table clears any round-by-round settings you already entered.

⏰ Timeout Default

Chooses what happens when a team does not submit before the round ends.

Auto KeepRecords Keep for the missing choice.
Auto CutRecords Cut for the missing choice.
Zero PayoffUses the default choice to resolve the opponent’s outcome, but gives the timed-out team zero payoff.

⏱️ Time Mode

Controls when matches advance, especially when several pairs play at different speeds.

⚡ Async (Fast)Each match advances independently as soon as its round resolves.
🐢 Sync (Wait Full Time)Completed matches wait until all active matches finish before the next round.
⚖️ Mixed (Grace +10s)A hybrid pacing option: fast play with a short grace window for slower matches.

🎁 Sudden Death (+2)

When enabled, participants initially see the planned match length, then two surprise rounds are added after the scheduled final round. This is useful for testing end-game effects.

The extra rounds copy the settings from the final scheduled round.

Round-by-round controls

⌛ Time(s)

The decision time for that round in seconds. When the timer expires, Timeout Default is applied.

Use 45 for normal discussion; use 15 to create time pressure.

🙈 Blind

Hides that round’s result and payoff from participants. The server still records the choices and scores.

Useful for studying decisions when immediate feedback is removed.

🔇 Silent

Disables participant chat for that round. Players must decide without sending messages, and chat-triggered bots stay silent.

🕵️ Spy Mode

Leaks selected opponent information in team games: the first line, first two lines, all team chat, or the opponent’s submitted/modified decision.

Inactive in 1 vs 1 because there is no private teammate discussion to spy on.

✏️ Modify

Allows a team to revise its submitted Keep/Cut choice while the round is still open. Each revision can incur the configured penalty.

🧾 Penalty

The HK$ amount deducted for each use of Modify. It only matters when Modify is enabled. Final payoff cannot fall below zero.

HK$100 × 2 revisions = HK$200 deducted.

📈 Skew

Multiplies both teams’ base payoffs for that round before modification penalties are deducted.

A 1.5 skew turns a HK$10,000 base payoff into HK$15,000.

📣 Admin Message

An optional note shown in the round-start system message. Use it for instructions, context, or experimental treatments.

🔀 Shuffle

Randomly reallocates human participants between the two teams after that round. It changes who works together in the next round.

Inactive in 1 vs 1. Use it only when changing group membership is part of the study design.
